# PFarma — Archivio temporaneo per media organici

Questo repository **pubblico** viene usato per rendere disponibili file video già pubblicati da PFarma durante la programmazione di post organici con Buffer.

- Non inserire access token Meta, credenziali Buffer, numeri di telefono, conversazioni o dati personali.
- Pubblicare solo materiale PFarma già reso pubblico, previa verifica del diritto di riutilizzare anche **musica e audio**.
- L'app privata `pfarma-social` seleziona solo Reel esistenti dell'account PFarma, verifica l'MP4 e carica file con autorizzazione circoscritta.
- I file sono pubblicamente accessibili e possono rimanere in cache o nella cronologia Git anche dopo la rimozione; **non trattare il repository come deposito effimero garantito**.
- Rimuovere i file dalla pubblicazione web dopo verifica dell'effettiva consegna su Buffer; evitare la rimozione anticipata.
- GitHub Pages è per pochi video e volumi contenuti, non una CDN/video host permanente.
